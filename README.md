# KOYA / Barça Match Lab

四葉紅夜をFCバルセロナに加えた架空世界線のサッカーシミュレーター。日本代表戦、複数シーズン、1試合ずつのシミュレーション、手動結果、スタッツ、結果リセットに対応します。

## GitHub Pagesで使う

静的アプリは **`docs/`** にあります。Node/PythonなどのサーバーやAPIキーは不要です。すべて相対パスなので `https://<owner>.github.io/ChatGPT_Simulation_Football/` のようなサブパスでも動きます。

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定します。
2. **Actions → Deploy KOYA to GitHub Pages → Run workflow** を実行します。以後 `main` の更新でチェック・公開されます。
3. 成功したデプロイに表示されるURLを開きます。

接続中のGitHubツールはリポジトリファイルを編集できますが、Pagesの有効化・設定変更をするAPIは利用できません。未有効の場合は上記1の設定が必要です。リポジトリの公開範囲は変更していません。非公開リポジトリのPages利用にはGitHub側の対応プランが必要です。GitHub Pagesの公開範囲はリポジトリの非公開設定とは別です。

Actionsを使わない場合は、PagesのSourceを「Deploy from a branch」、Branchを `main` / `/docs` にしても使えます。その場合、このリポジトリのActionsワークフローは無効化してください。

## 収録データ

| シーズン | 試合数 | 内容 |
| --- | ---: | --- |
| 2023–24 | 59 | 添付の日程57試合＋添付末尾のスーペルコパ2試合。4冠の世界線 |
| 2024–25 | 70 | 本文63試合＋2025クラブW杯7試合。クラブW杯まで同じシーズンに所属 |
| 2025–26 | 63 | 本文の全日程。グアダラハラ戦はIF振替の2025年12月23日 |
| 2026–27 | 43 | 既存アプリのリーガ38節＋確認済みCL第4〜8節のスナップショット |

23–26のデータは**ユーザーが提示したIF設定**です。現実の公式成績とは区別しています。25–26の63戦全勝、各シーズンのタイトルは物語の前提であり、未記録のスコアや詳細スタッツを捏造していません。シミュレーション結果は前提を自動強制しません。確定した展開は手動入力で保存してください。

24–25・25–26は本文にH/A・会場の指定がないため、会場を未設定として保持します（シミュレーションのホーム補正なし）。23–24は添付にあるH/A・中立地を保持します。全シーズンの基本メンバーは添付の2026–27設定をテンプレートとして使用するため、必要に応じてスカッド画面で各シーズン用に編集してください。

- 元資料：`data/sources/`
- 配布用JSON：`docs/data/fixtures-2023-24.json` など
- ブラウザ用データ：`docs/historical-data.js`
- 再生成：`python3 scripts/build_fixtures.py`
- 検証：`node tests/check.cjs`

JSONのメタデータと各試合に出典種別を持たせ、日付・大会ラウンド・対戦相手・シーズン・会場情報・IF振替注記を保存しています。出典文書中の指示文は実行せず、設定データとして扱っています。

## 以前のSites版から記録を移す

結果・独自日程・メンバー設定は各ブラウザのlocalStorageに保存され、GitHubへ自動送信しません。異なるURL間では自動で共有されません。

1. 以前のアプリで「記録を書き出す」を押してJSONを保存します。
2. GitHub Pages版で「記録を読み込む」からJSONを選びます。
3. 確認画面で件数・上書き対象を確認して読み込みます。

v1/v2バックアップに対応。同じIDの記録は確認後に読み込み内容で更新し、他の記録は保持します。ブラウザ保存だけの個人記録は、このリポジトリには含まれません。

## ローカル起動

```sh
python3 -m http.server 8000 --directory docs
```

`http://localhost:8000/` を開きます。ネットワークはアプリの配信にだけ使用し、シミュレーション自体はブラウザ内で動きます。
