## 2. シーズンごとの獲得タイトル

### 2023-24シーズン：4冠

シャビ監督の下、紅夜が15歳でトップチームへ昇格した最初のシーズンです。

| 大会             | 結果 | 決勝・代表的な試合     |
| -------------- | -- | ------------- |
| スーペルコパ         | 優勝 | レアル・マドリード 4-1 |
| コパ・デル・レイ       | 優勝 | マジョルカ 6-2     |
| ラ・リーガ          | 優勝 | 4月29日に優勝決定    |
| UEFAチャンピオンズリーグ | 優勝 | レアル・マドリード 9-6 |

主な記録

- 全公式戦勝利、チーム年間230得点。
- 紅夜はヘタフェ戦でトップチームデビューし、2得点2アシスト。
- 2023年10月28日のクラシコでは10-1で勝利し、紅夜は3得点4アシスト。
- CL決勝ではレアル・マドリードを9-6で下し、紅夜がハットトリック。

### 2024-25シーズン：7冠

| 大会                 | 結果 | 決勝・代表的な試合     |
| ------------------ | -- | ------------- |
| UEFAスーパーカップ        | 優勝 | アタランタ 8-3     |
| FIFAインターコンチネンタルカップ | 優勝 | パチューカ 18-3    |
| スーペルコパ             | 優勝 | レアル・マドリード 5-0 |
| コパ・デル・レイ           | 優勝 | レアル・マドリード 9-3 |
| ラ・リーガ              | 優勝 | 2連覇           |
| UEFAチャンピオンズリーグ     | 優勝 | PSG 7-5       |
| FIFAクラブワールドカップ     | 優勝 | チェルシー 6-2     |

このシーズンは、参加した7大会すべてで優勝した歴史的な一年です。

特にCL決勝でPSGを7-5で破り、バルセロナは欧州連覇を達成。さらに2025年7月のクラブワールドカップでも頂点に立ち、年間7冠を完成させました。

### 2025-26シーズン：6冠

ハンジ・フリック監督が率いた最初のシーズンです。

| 大会                 | 結果 | 決勝・代表的な試合           |
| ------------------ | -- | ------------------- |
| UEFAスーパーカップ        | 優勝 | トッテナム 3-1           |
| FIFAインターコンチネンタルカップ | 優勝 | フラメンゴ 8-1           |
| スーペルコパ             | 優勝 | レアル・マドリード 6-2       |
| コパ・デル・レイ           | 優勝 | レアル・ソシエダ 4-1        |
| ラ・リーガ              | 優勝 | 5月10日のクラシコ 5-0で優勝決定 |
| UEFAチャンピオンズリーグ     | 優勝 | PSG 5-3             |

2026年5月30日のCL決勝で、PSGに5-3で勝利。

バルセロナ史上初のCL3連覇が完成しました。

紅夜は決勝で壁の隙間を通す直接フリーキックを決め、チームの勝利に貢献しています。

この時点で、紅夜加入後の3シーズンに参加したタイトル対象大会をすべて制し、累計17冠となりました。

## 5. 特に重要なクラブ記録

\*\*CL3連覇（2023-24〜2025-26）\*\*は、紅夜加入後の最大の歴史的記録です。決勝のスコアは、レアル・マドリードに9-6、PSGに7-5、再びPSGに5-3。3回の決勝だけで21得点を奪っています。

また、2023-24シーズンからリーガ、コパ、スーペルコパの国内3大会をそれぞれ3連覇し、2024-25には年間7冠を達成。2025-26までの3シーズンで17タイトルを獲得しています。

現時点の重要な記録は、「加入後18冠・CL3連覇・国内主要3大会3連覇」です。

なお、2023-24〜2025-26の全試合の個別スコアがまだ完全には記録されていないため、加入後の通算勝利数・引き分け数・敗戦数・総得点・総失点は未確定として扱うのが正確です。これらは今後、過去シーズンの試合結果を補完すれば完全なクラブ記録表にできます。
